# TermFinder

A modern terminal + file explorer for macOS, Windows, and Linux, built with Electron.

> **Note**: This repository hosts the binary releases for TermFinder. The source code is maintained in a private repository.

## 📥 Download

**[👉 Click here to download the latest version](https://github.com/evercodeme/termfinder-releases/releases)**

Supports:
-   **macOS** (Verified for Apple Silicon & Intel)
-   Windows & Linux (Coming soon)

## ✨ Features

### Terminal Integration
-   🖥️ **Multi-tab terminal** with full xterm.js support
-   🔄 **Shell Integration**: Terminal navigations automatically update the file explorer view
-   ⌨️ **Pro Shortcuts**: `Cmd+T` (New Tab), `Cmd+W` (Close Tab), `Cmd+1-9` (Switch Tab)

### Smart File Management
-   📂 **Integrated File Explorer**: Always in sync with your terminal path
-   🔍 **Smart Previews**: View images, code, and text files instantly (auto-detects binary files)
-   📋 **Favorites Sidebar**: Drag-and-drop your most used folders
-   💾 **Disk/Volume List**: Fast access to all mounted drives

### Remote Capabilities (SSH/SFTP)
-   🌐 **Seamless SSH**: `ssh user@host` opens a fully integrated remote session
-   📁 **SFTP Browser**: Browse remote files as if they were local
-   🔐 **Secure**: Passwords stored safely in system Keychain; Private keys supported

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Cmd+T` | New Tab |
| `Cmd+W` | Close Tab |
| `Cmd+1-9` | Switch to Tab |
| `Cmd+Shift+[` | Previous Tab |
| `Cmd+Shift+]` | Next Tab |
| `Cmd+,` | Open Settings |
| `Cmd+L` | Clear Terminal |

## Installation (macOS)

1.  Download the `.dmg` file from the [Releases page](https://github.com/evercodeme/termfinder-releases/releases).
2.  Open the `.dmg` file.
3.  Drag **TermFinder** to your **Applications** folder.
4.  **Note**: On first launch, you may need to Right-click -> Open to bypass security verification.
